# DIY 项目投稿

欢迎分享你用 Muse Gadgets 造的东西！提 PR 在这个目录新增一个 Markdown 文件即可。

## 投稿格式

```markdown
# 项目名

- 作者：（你的名字/网名 + 链接）
- 硬件：（板子型号 + 外设，如 ESP32-S3-BOX-3 + 温湿度传感器）
- 成本：（约 ¥xxx）
- 耗时：（约 x 小时）
- 状态：（已实测 / 转述 / 进行中）
- 仓库/视频：（链接）

## 做了什么
一句话 + 一张图/视频。

## 步骤
1. ...
2. ...

## 避坑
- ...
```

## 收录标准

1. 真实存在：有代码仓库、视频或详细图文其一
2. 每条必须标注状态：**已实测**（投稿人亲手跑通）/ **转述**（媒体/他人报道）/ **进行中**
3. 不编造未经核实的步骤，不确定的写"待验证"
